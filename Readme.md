# Fine-Tuning with LoRA

## LoRA Pipeline

This project explores efficient LLM fine-tuning using Low-Rank Adaptation (LoRA).

### Project Goal

Fine-tune a small language model for structured function-calling using LoRA and evaluate its performance before and after fine-tuning.

### Pipeline

Raw Dataset
↓
Data Cleaning
↓
Normalization
↓
Token Length Filtering
↓
Train / Validation / Test Split
↓
LoRA Fine-Tuning
↓
Evaluation
↓
Before vs After Comparison
